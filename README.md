# Mathias Heider

Ph.D. candidate in Computer Science at the University of Delaware. I am an NSF NRT Fellow at the Center for Composite Materials and part of AIM for Composites, a DOE Energy Frontier Research Center.

I build AI systems for manufacturing and materials, and I build them so their answers can be checked.

- **[Manufacturing Intelligence Pipeline](https://github.com/mathheider/manufacturing-intelligence-pipeline).** My thesis. A vision-language model reads a photo of a part, and a rule engine written from manufacturing textbooks ranks how it was made and shows the rules behind each ranking. The repository holds the code, both rule bases, the benchmarks and every result file.
- **An autonomously built composites database.** A service that read 10,720 open-access documents and extracted 2.27 million property values with no person in the loop, and a set of physics and cross-paper checks that test those values against each other. Paper in preparation.
- **Before the Ph.D.** HPC performance engineer at Cornelis Networks. B.S. in Mathematics and Economics.
